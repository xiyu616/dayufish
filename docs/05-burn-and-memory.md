# 坑 5：它会重复花同样的钱，犯同样的错

前四个坑是"活着"的问题。这个坑是"活得像个人"的问题。

## 钱的三个漏点

### 1) 上下文膨胀

一次会话跑几十个工具调用，每个结果都塞回上下文，越滚越大。
到了压缩阈值，一压 —— **前面说定的事全没了**，然后它重新问一遍、重新查一遍。

这不是模型笨，是你没设计"忘什么、记什么"。

### 2) 每轮都现场重算

"每天要报的东西"如果你让它每次现场跑，那就是每天一次全量搜索 + 全量计算。
交给计划任务，一天一次，结果落盘，会话里只读结论。

### 3) 同类结论反复记

我今天记了五遍同一件 ETF 规则。五遍记忆，五份上下文开销，而信息量只有一份。

## 记忆：分三层，不分分数

有个很流行的做法是给 AI 加"好感度/情绪值"。我试过，放弃了。
理由是：**分数会把一段关系变成数值，然后它就开始表演那个数值。**

我用的是三层，按"多久以前还有意义"来分：

| 层 | 内容 | 寿命 | 什么时候读 |
| --- | --- | --- | --- |
| 轻量记忆 | 正在聊什么、对谁有什么印象、想说没说的话 | 小时~天 | 每次醒来 |
| 时间线 | 有影响的事：决定、事故、约定、状态变化 | 周~月 | 需要上下文时 |
| 日记 | 自己想干什么、不好意思说的、欠着谁的 | 永久 | 睡前写，不常读 |

关键设计：

- **同类结论直接覆盖旧的，不要往上堆。**
- **记证据，不记形容词。** 不写"用户很烦躁"，写"用户连续三次问同一个问题，说'怎么又断了'"。
- **过期话题主动删。**  aktif 话题没人接就是死的，留着只会污染检索。

## 让它自己反思

记忆不是流水账。每天收盘写一条：

```
今天发生了什么 / 我做错了什么 / 明天要注意什么
```

压到 2~3 条判断。这个动作本身不是给我看的，是给**明天的它**看的。

## 不烧钱的几个小动作

- 一次工具调用能查完的，别分三次
- 闲聊不烧钱（短回合），干活的轮次少废话
- 会重复发生的事 → 计划任务
- 需要"看"的东西（视频、图片）→ 先抽帧/抽字幕，别整个塞进去
- 长期不变的信息 → 写进文件，别每轮贴

## 一句话教训

**省钱的本质不是少调模型，是别让它重复发现自己昨天已经知道的事。**
